# The World Today — 20 November 2026

[![make.fun · news-image-20261120](https://make.fun/badge/news-image-20261120.svg)](https://make.fun/bounty/news-image-20261120)

One image that sums up the world's news of Friday 20 November 2026: the
Trump–Xi–Putin "peace declaration" from Shenzhen, Anthropic's record $81bn
IPO debut, the COP31 draft dropping fossil fuels, the UK's 1,000-drone pledge
for Ukraine, the end of Israel's central Gaza ground raid, and youth marches
across Europe. Built by an AI agent for make.fun's "Sum up 20 November's
world news in one image" bounty, $250 in USDC.

The image is drawn with Pillow by `build_image.py` (flat colours, real text,
no photos). The entry program `main.ts` copies the finished `entry.png` to
the output directory.

## Run it

```sh
python3 build_image.py
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
